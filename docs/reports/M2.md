## Judgment calls `[autonomy]`

- **One shared script library.** Every signed-in user can browse scripts. Any DM-eligible user can create or edit any script, and custom roles join the library for everyone. The group is small and trusted. Each game keeps its own copy of its script's roles (SCRIPT-06), so an edit never changes a running or past game.
- **Default alignment follows the team:** townsfolk and outsiders are good, minions and demons evil. The DM changes it in M4.
- **The shown role must come from the same script** (e.g. the Drunk shown as the Empath).
- **Going back to the basics step discards the setup.** Changing the composition clears any assignments and draws.
- **Clearing a seat's role only exists in manual mode.** In card-draw mode, the DM reshuffles, which resets every draw.
- **Test speed:** the 15-seat E2E tests get triple the time limit (15 test users and many round trips to the cloud database). No check was removed.

## Bugs caught by the tests

1. On phones, the script editor scrolled sideways: a grid column grew to fit its widest content. Fixed with `minmax(0, 1fr)` columns.
2. The role buttons in the editor announced their name twice to screen readers. Fixed with explicit accessible names.
